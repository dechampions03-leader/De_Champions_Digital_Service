This private admin tool runs one simulated MTN data purchase against VTpass Sandbox. It does not charge a customer, use Flutterwave, create a DCDS order, or touch Production.

Before you continue: Sign in to the DCDS Development preview with your root administrator account. The server independently checks your administrator permission. The test uses VTpass's documented sandbox test number 08011111111.
